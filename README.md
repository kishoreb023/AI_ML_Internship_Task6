# 🧠 AI & ML INTERNSHIP TASK 6 – K-Nearest Neighbors (KNN) Classification

## 📌 Objective:
Implement and understand K-Nearest Neighbors (KNN) algorithm for classification problems using the Iris dataset.

---

## ✅ Key Steps:
- Load and explore the Iris dataset
- Normalize features for fair distance calculations
- Train KNN models with varying values of `K`
- Evaluate using:
  - Accuracy score
  - Confusion matrix
- Visualize:
  - Decision boundaries
  - Value of `K` vs Accuracy

---

## 🧰 Tools and Libraries Used:
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

---

## 📈 Results:
- Identified optimal value of `K` for best accuracy
- Observed high classification performance on Iris dataset
- Clearly visualized decision boundaries and the impact of `K`

---

## 📁 Files Included:
- `TASK-6_KNN_Classification.ipynb` – Complete notebook with code and output
- `Iris.csv` – Dataset used for the task
- `README.md` – Task summary and documentation

---

## 📊 What You'll Learn:
- Fundamentals of instance-based learning
- Importance of feature scaling in distance-based algorithms
- Role of distance metrics
- How to choose the right value of `K`
